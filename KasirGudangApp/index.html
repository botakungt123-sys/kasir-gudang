Catat pembelian barang

Semua bahan dan wadah (cup, box, sedotan, kantong) masuk lewat sini. Barang yang sudah ada: pilih di daftar. Barang yang belum pernah dibeli: tekan Beli barang baru.

Contoh: 1 pack Rp 20.000 isi 18 → stok +18, HPP Rp 1.111 per satuan. Beli eceran: isi per pack = 1.

Satu baris per menu terjual, ditambah satu baris kemasan per transaksi bila ada. Profit = omzet − potongan aplikasi − modal (harga beli × qty).

Modal (sepanjang waktu)

Modal awal otomatis = semua uang yang sudah dibayarkan untuk belanja stok; pembelian kredit baru dihitung setelah ditandai lunas, dan sementara itu tampil sebagai utang ke pemasok. Jadi perkiraan kas = uang bersih dari penjualan. Matikan centang di Pengaturan bila modal awal ingin diisi sendiri; perkiraan kas lalu = modal awal − belanja yang sudah dibayar + uang bersih dari penjualan. Biaya lain (sewa, gaji, listrik) belum dihitung.

Integrasi aplikasi ojol

Status: belum tersambung. Pesanan GoFood, GrabFood, dan ShopeeFood akan masuk otomatis ke kotak Pesanan masuk di Kasir setelah akses API dari masing-masing aplikasi didapat. Sementara itu, coba alurnya dengan pesanan simulasi; pesanan simulasi tidak mengubah apa pun sampai Anda menyimpannya sebagai transaksi.

Kunci API per toko

Isi dengan kunci dari masing-masing aplikasi untuk toko yang sedang login. Setiap akun toko menyimpan kuncinya sendiri. Kunci rahasia hanya dikirim ke server dan tidak bisa dibaca kembali dari aplikasi; yang ditampilkan hanya 4 karakter terakhir. Pesanan baru masuk otomatis setelah server integrasi aktif.

Halaman di dalam Claude tidak menyimpan kunci rahasia. Isi kunci API di aplikasi Android.

Printer struk

Pilihan ini tersimpan per perangkat. Bluetooth langsung hanya untuk printer BLE dan printer perlu dipilih lagi setelah aplikasi ditutup. Printer Bluetooth klasik: pasang aplikasi RawBT, sambungkan printer di sana, lalu pilih Lewat aplikasi RawBT. Jumlah karakter per baris mengikuti Lebar kertas struk (58 mm = 32, 80 mm = 48).

Akun dan cadangan data

Masuk sebagai . Ekspor menyimpan semua data ke satu file JSON. Impor menambahkan isi file ke data sekarang; data dengan kode yang sama ditimpa.

Kemasan per pesanan

Kemasan otomatis terisi di nota sesuai menu yang dipesan: tiap porsi makanan memakai kemasan makanan (misalnya mika), tiap porsi minuman memakai kemasan minuman (misalnya cup dan sedotan), ditambah kemasan sekali per pesanan (misalnya kantong). Kasir tetap bisa mengubah jumlahnya di nota. Biaya kemasan masuk HPP dan ikut dihitung di harga jual otomatis menu, tetapi tidak tercetak di struk. Kategori menu diatur di tab Menu.

Jika otomatis dicentang, harga di aplikasi dinaikkan supaya uang bersih setelah komisi sama dengan harga jual langsung: harga jual ÷ (1 − komisi), dibulatkan ke atas sesuai pilihan Pembulatan harga.
