Jam ramai

Jurnal profit

WaktuSaluranBarangQtyHarga beliHarga jualModalOmzetPotonganProfit

Satu baris per menu terjual, ditambah satu baris kemasan per transaksi bila ada. Profit = omzet − potongan aplikasi − modal (harga beli × qty). Diskon dicatat satu baris per transaksi.

Modal (sepanjang waktu)

Modal awal otomatis = semua uang yang sudah dibayarkan untuk belanja stok; pembelian kredit baru dihitung setelah ditandai lunas, dan sementara itu tampil sebagai utang ke pemasok. Jadi perkiraan kas = uang bersih dari penjualan. Matikan centang di Pengaturan bila modal awal ingin diisi sendiri; perkiraan kas lalu = modal awal − belanja yang sudah dibayar + uang bersih dari penjualan. Biaya operasional yang dicatat di Pembelian ikut mengurangi perkiraan kas.

Akun kasir

Kasir tidak memakai email. Buat satu kode untuk tiap kasir, lalu kasir memasukkannya di layar masuk, bagian Kasir. Kode hanya bisa dipakai sekali, di satu HP. Kasir hanya bisa berjualan dan melihat stok (tanpa HPP), dan wajib mengisi nama pemesan. Penjualan kasir masuk laporan dan memotong stok saat aplikasi owner ini terbuka dan online.

Integrasi aplikasi ojol

Status: belum tersambung. Pesanan GoFood, GrabFood, dan ShopeeFood akan masuk otomatis ke kotak Pesanan masuk di Kasir setelah akses API dari masing-masing aplikasi didapat. Sementara itu, coba alurnya dengan pesanan simulasi; pesanan simulasi tidak mengubah apa pun sampai Anda menyimpannya sebagai transaksi.

Kunci API per toko

Isi dengan kunci dari masing-masing aplikasi untuk toko yang sedang login. Setiap akun toko menyimpan kuncinya sendiri. Kunci rahasia hanya dikirim ke server dan tidak bisa dibaca kembali dari aplikasi; yang ditampilkan hanya 4 karakter terakhir. Pesanan baru masuk otomatis setelah server integrasi aktif.

Halaman di dalam Claude tidak menyimpan kunci rahasia. Isi kunci API di aplikasi Android.

Logo toko

Warna langsung terlihat saat dipilih; tekan Simpan pengaturan di bagian atas supaya tersimpan. Gambar dan logo otomatis dikecilkan lalu langsung tersimpan, dan berlaku untuk semua perangkat toko ini. Di printer thermal logo dicetak hitam-putih, jadi logo sederhana dengan kontras tinggi paling bagus.

QRIS toko

Masukkan QRIS statis toko Anda (dari GoBiz, bank, atau e-wallet bisnis). Saat pelanggan bayar QRIS, aplikasi membuat kode QR yang nominalnya sudah terisi sesuai total belanja. Konfirmasi tetap manual: cek notifikasi uang masuk sebelum menyimpan transaksi. Uji dulu sekali dengan nominal kecil.

Printer struk

Pilihan ini tersimpan per perangkat. Bluetooth langsung hanya untuk printer BLE dan printer perlu dipilih lagi setelah aplikasi ditutup. Printer Bluetooth klasik: pasang aplikasi RawBT, sambungkan printer di sana, lalu pilih Lewat aplikasi RawBT. Jumlah karakter per baris mengikuti Lebar kertas struk (58 mm = 32, 80 mm = 48).

Akun dan cadangan data

Masuk sebagai . Ekspor menyimpan semua data ke satu file JSON. Impor menambahkan isi file ke data sekarang; data dengan kode yang sama ditimpa.

Kemasan per pesanan

Kemasan otomatis terisi di nota sesuai menu yang dipesan: tiap porsi makanan memakai kemasan makanan (misalnya mika), tiap porsi minuman memakai kemasan minuman (misalnya cup dan sedotan), ditambah kemasan sekali per pesanan (misalnya kantong). Kasir tetap bisa mengubah jumlahnya di nota. Biaya kemasan masuk HPP dan ikut dihitung di harga jual otomatis menu, tetapi tidak tercetak di struk. Kategori menu diatur di tab Menu.

Nama di aplikasi ojol (untuk pesanan otomatis)

Isi bila nama menu di GoFood, GrabFood, atau ShopeeFood berbeda dari nama di sini; pisahkan dengan titik koma (;) bila ada lebih dari satu nama. Kosongkan bila sama. Nama baru juga tersimpan otomatis saat Anda mencocokkan pesanan masuk.

Isi menu

Bila satu satuan bahan dibagi ke beberapa porsi, isi "Untuk berapa porsi". Contoh: 1 pcs ayam untuk 8 porsi berarti HPP ayam per porsi = HPP 1 pcs ÷ 8, dan stok ayam berkurang 1/8 pcs setiap porsi terjual.

Pilihan pelanggan (opsional)

Buat satu grup untuk tiap hal yang dipilih pelanggan, misalnya Saus, Bagian ayam, Minuman. Di setiap grup pelanggan memilih satu. Isi tambahan harga 0 untuk pilihan gratis. Pilihan boleh berupa bahan atau menu lain (misalnya Es Teh), dan bahan serta kemasannya ikut dihitung. Bahan boleh dikosongkan, misalnya untuk "Tanpa minuman".
